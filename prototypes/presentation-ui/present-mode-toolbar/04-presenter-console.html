04 — Presenter Console

A Keynote-style dual-view presenter layout: the main slide fills the left and a dedicated right console panel shows the next slide, speaker notes, elapsed timer, and progress — all without any floating overlay.

  • Current slide fills the entire left pane in an authentic 16:9 frame — no overlaid chrome interrupts the view
  • Right console panel uses --ds-stage-panel / --ds-stage-border / --ds-stage-text token family for a darker, contrast-checked dark-theme surface
  • Large 22 px tabular-numeric timer in the console header gives the speaker immediate elapsed-time feedback
  • Next-slide thumbnail preview (16:9 micro-frame) lets the speaker preemptively frame their segue
  • Speaker notes scroll independently; bottom nav bar provides prev/next + secondary tools as a persistent footer
