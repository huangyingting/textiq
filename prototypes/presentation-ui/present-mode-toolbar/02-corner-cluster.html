02 — Corner Cluster

Three independent glass capsules anchored in the stage corners — each capsule owns a distinct concern, giving the slide maximum uncluttered space in the centre.

  • Navigation + counter lives in the bottom-left capsule; the counter sits between the arrows for the shortest eye-travel distance
  • Presentation tools (notes, overview, shortcuts, exit) group in the bottom-right capsule — secondary actions away from the primary nav flow
  • Status data (elapsed timer + fullscreen) floats in the top-right — time is visible at a peripheral glance without interrupting the speaker's eyeline
  • An optional laser-active indicator capsule appears top-left — uses --ds-danger dot + --ds-shadow-laser-indicator glow ring
  • Each capsule is fully independent: any one could be hidden without breaking the others
