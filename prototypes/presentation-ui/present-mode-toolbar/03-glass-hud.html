03 — Glass HUD

A full-width translucent band docked to the stage floor — the progress track runs edge-to-edge at its very top, with slide-dot navigation in the centre so you can jump by eye.

  • Full-width glass band using --ds-inverse-surface + 28 px backdrop-blur occupies the stage edge without hard borders
  • A 2 px accent progress line at the top of the band doubles as a visual progress indicator and stage separator
  • Centre zone: 24 slide dots — done = muted, current = indigo pill capsule, future = dim — enables at-a-glance deck position
  • Left zone owns primary navigation (prev · counter · next); right zone holds secondary tools + timer chip
  • Three-zone layout keeps the presenter's eye moving left-to-right in a predictable reading order
