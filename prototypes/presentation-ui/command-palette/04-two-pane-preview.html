04 — Two-Pane Preview

Raycast / Arc–style split palette: a scrollable command list on the left and a persistent detail pane on the right. Selecting a row instantly populates label, description, section, and shortcut in the preview — reducing the "what does this do?" ambiguity for less-familiar commands.

  • 680 px panel; left list is fixed 240 px, right preview flexes to fill — both scroll independently.
  • Active row: --ds-state-selected bg + accent ArrowRight indicator pointing at the preview.
  • Preview pane: accent icon box, title, description, section badge, optional shortcut kbd chip, and an accent Run button.
  • Empty list state replaced by muted "no results" text in the preview pane area.
  • Full-width search header sits above both panes; ⌘K hint uses paired --ds-surface-sunken key chips.
