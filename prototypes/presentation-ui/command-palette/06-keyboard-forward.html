06 — Keyboard Forward

A shortcut-first command palette where keyboard bindings are the hero, not an afterthought. Commands are laid out in a fixed-column grid: shortcuts column (right-aligned) · icon · label · section. Commands without shortcuts show a muted "–" marker so the pattern is never broken. A "Shortcuts only" filter tab narrows the list instantly.

  • 4-column CSS grid per row: 96 px shortcut column, 20 px icon, flex label, auto section — perfectly aligned across all rows.
  • Shortcut kbd chips use --ds-surface-sunken + --ds-border-subtle + --ds-font-mono; active row shifts them to --ds-accent-surface + accent border.
  • Filter tabs (All / Shortcuts only) sit at the header border; active tab "lifts" onto the content surface — a classic tab panel affordance.
  • Column header labels (Shortcut, Command, Section) orient new users instantly.
  • Empty state shown when "Shortcuts only" tab finds no shortcut-bearing results matching the query.
