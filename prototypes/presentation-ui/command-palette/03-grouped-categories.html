03 — Grouped Categories

Linear Doc / Notion-style palette with sticky section headers. Commands are organised into labelled groups (Deck, Export, Insert, Inspector) so users can scan by workflow area, not just by keyword.

  • Section headers: 10 px all-caps muted label + count badge; groups separated by subtle hairlines.
  • Accent icon in palette header signals the ⌘K entry point; search field uses --ds-surface-sunken with focus ring.
  • Active row: --ds-accent-subtle fill + 1 px --ds-accent-border outline (no left bar — category grouping provides structure).
  • Disabled rows fade to 40 % — visible but clearly non-interactive.
  • Scrollable results (max 380 px) with thin webkit scrollbar matching border token.
