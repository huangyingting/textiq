Command Palette (⌘K) — 6 Design Directions

Six distinct, compact, modern approaches to the shared Command Palette of the TextIQ presentation editor. Each solution is a self-contained HTML file grounded in src/components/presentation/slide-command-palette.tsx and the SlideCommandPaletteCommand shape. All share one source of truth — ../design-tokens.css.

6 directions 0 CDN / frameworks Tokens from design-tokens.css Grounded in slide-command-palette.tsx

Open any card below directly in your browser — no build step, no network required. Each file renders the palette centered over a dimmed mock slide editor. Type zzz in any search box to trigger the empty / no-results state. Each file has a spec header (rationale + 3–5 bullet points) above the demo.

Raycast-style split palette. Left scrollable list (240 px) + right detail pane with icon, description, section badge, shortcut, and a Run button.

05

Minimal Flat

Open →

Borderless, airy, typography-first palette. Semantic-color accent dots replace icon boxes. 40 px rows, 14 px labels, pure shadow elevation. No section pills in the list.

Keyboard Forward

Open →

Shortcut-first 4-column grid: shortcut column (96 px, right-aligned) · icon · label · section. A "Shortcuts only" filter tab surfaces keyboard-navigable commands instantly.
