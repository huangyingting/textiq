05 — Minimal Flat

Borderless, airy, typography-first palette. No icon boxes, no section pills — just a colored accent dot, a clean label, and a right-aligned section name. The design trusts whitespace to do the heavy lifting, letting the content breathe.

  • 520 px panel with no hard border — a hairline ring shadow + --ds-shadow-overlay creates subtle elevation.
  • Rows are 40 px (generous) with 14 px labels; semantic-color accent dots replace icon boxes (green = export, indigo = deck, amber = insert, violet = inspector, cyan = help).
  • Active row uses --ds-state-selected fill only — no left bar, no outline, no ring; typography weight change signals selection.
  • Footer is a centered pill row of paired key hints — equally spaced, unobtrusive.
  • Empty state uses a simple muted circle icon + two lines of copy, no heavy illustration.
