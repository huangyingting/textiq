06 · Two-Zone Balanced

A clear left/right layout with explicitly equal visual weight. Left holds slide context (position, selection, panel toggles); right holds view controls (zoom, save, presence). A subtle center tick marks the balance axis.

  • CSS grid: 1fr / auto / 1fr — ensures true left–right balance regardless of content
  • Center tick (1px, border-subtle) anchors the visual midpoint
  • Left zone: slide position badge + context text + panel toggles
  • Right zone: diagnostics, source count, zoom pair, save status, presence
  • Zoom uses a flat sunken pair [−][value ▾][+] with internal dividers
