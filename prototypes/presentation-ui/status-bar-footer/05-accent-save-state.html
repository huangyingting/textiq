05 · Accent Save State

Save status is the clear visual focal point — a distinct filled chip that shifts color and content to reflect the document state. Collaboration presence avatars are large and colorful. Everything else stays muted.

  • Save chip: accent indigo (Saved) → amber (Unsaved) → red (Error) — always visible
  • Presence avatars: 22px solid-color circles, scale on hover, overlap with white ring
  • All other controls (zoom, toggles, diagnostics) use muted text — visual hierarchy is intentional
  • Save chip has semantic border + background shift; no icon dependency
