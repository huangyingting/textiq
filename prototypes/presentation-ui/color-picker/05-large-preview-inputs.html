05 — Large Preview + Inputs

Power-user layout inspired by design tools. A 52×52 current-color chip dominates the top-left with a hex input + R/G/B channel fields to the right — precise numeric entry first. Presets appear below as a compact scrollable pool, demoted to a supporting role.

  • Large color preview chip updates live; clicking it cycles to transparent/none state
  • Hex input with inline # prefix and copy-to-clipboard button; RGB channel fields update automatically
  • Eyedropper button spans the full width for ergonomic finger-target area
  • 24 preset swatches below the divider in a flexible wrap layout — fill is hardcoded hex (content), rings use --ds-focus-ring (chrome)
  • None/transparent button paired with preview for immediate "clear fill" access
