06 — Minimal Dots

An ultra-compact, borderless dot strip designed for inline toolbar integration. No panel, no labels, no padding — just a pill-shaped floating row of 18px color circles. The selected dot carries the accent ring; tapping "+" reveals a compact hex-input row within the same pill. Perfect for text-color and highlight-color toolbar buttons.

  • Floating pill shape (full border-radius) — looks native beside toolbar buttons; no box-like panel chrome
  • 18px circle dots: --ds-radius-pill swatches from DEFAULT_SWATCH_PRESETS; fill is hardcoded hex (content)
  • None/transparent dot (checkerboard + red diagonal) and "+" add-custom dot flank the color circles
  • Selected dot: --ds-focus-ring ring with offset, white checkmark + drop-shadow for visibility
  • "+" toggles an inline hex input row (monospace, --ds-font-mono) + eyedropper — expands pill height, never width
