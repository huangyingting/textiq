04 — Theme-Aware Sections

Three collapsible sections mirror how a slide template thinks: the active document's Theme palette surfaces first with larger swatches and role labels (Primary, Background…), then the full Standard preset grid, then Recent used colors. The hierarchy matches how users actually pick colors.

  • Theme section sits above Standard — larger 28px swatches with role names ("Primary", "Bg", "Text", "Accent", "Alt")
  • Each section collapses with a chevron — Standard defaults open, Recent closed; Theme always open
  • Standard section: full 4×6 grid of DEFAULT_SWATCH_PRESETS with selected ring + checkmark
  • Recent row: 6 recently-used swatches for quick repeat access
  • Custom section: hex input on --ds-surface-sunken + eyedropper + none/transparent button
