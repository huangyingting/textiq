03 — Compact Row

Maximum density for tight inspector panels. All 24 presets fit into three rows of 8 tiny swatches with near-zero gap. A single utility bar below holds the transparent/none swatch, a hex input, and an eyedropper — nothing is hidden, everything is reachable in one view.

  • 8 × 3 dense grid of 20px swatches — smallest swatch size from Swatch.tsx (sm=20px)
  • Recent-colors micro-row sits above the dense grid for last-used quick access
  • Transparent/none swatch uses checkerboard + red diagonal slash — no separate modal or menu
  • Selected swatch carries --ds-focus-ring ring; hover scale-up avoids misclick on adjacent swatches
  • Hex input on --ds-surface-sunken with eyedropper; full panel fits in ≈206px × 136px
