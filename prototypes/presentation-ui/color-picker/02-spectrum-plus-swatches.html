02 — Spectrum + Swatches

A hue-rainbow strip plus saturation/value square at the top lets users define any custom color visually, while a compact two-row preset palette below speeds up common choices. No tabs needed — both workflows coexist in one compact panel.

  • Full-width hue strip (CSS gradient) with thumb indicator; SV square shows hue-tinted white→black gradient
  • Alpha slider beneath the gradient area; large current-color chip reflects all changes in real-time
  • Compact 20px preset swatches from DEFAULT_SWATCH_PRESETS in a wrapping flex row
  • Selected swatch: --ds-focus-ring ring, white checkmark with drop-shadow
  • Hex input on --ds-surface-sunken + eyedropper complete the custom-color workflow
