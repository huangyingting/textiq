01 — Swatch Grid Classic

The canonical inspector-panel color picker. Two labeled sections (Recent + Standard) with a dense 4×6 preset grid, a transparent/none action, and a combined hex-input + eyedropper row. Immediately familiar, dense, functional.

  • 6-column swatch grid using all 24 DEFAULT_SWATCH_PRESETS hex values from color-picker.tsx
  • Recent-colors row sits above the grid separated by a labeled section divider
  • Selected swatch: accent ring (--ds-focus-ring) with white checkmark + drop-shadow — matches Swatch.tsx exactly
  • None button (Ban icon) clears the fill; hex input uses --ds-font-mono on --ds-surface-sunken
  • Eyedropper (Pipette) affordance placed in the action row for custom color sampling
