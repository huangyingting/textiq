06 · Filmstrip Rows

One horizontal scrollable filmstrip row per template group delivers a streaming-service browse feel — all 8 groups visible at once without vertical scroll.

  • Tall modal dialog over dimmed editor — fixed height with no outer scroll
  • Eight labeled rows, each a horizontally scrollable filmstrip of template cards
  • Cards show a 16:9 wireframe thumbnail with the template name below; selected card gets accent ring
  • Edge fade gradients (CSS mask) signal scrollable overflow within each row
  • Search + density segmented control in the header; Author Brand Kit button alongside
