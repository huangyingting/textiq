05 · Compact Tiles

Speed-optimised "quick pick" — a compact popover anchored to the add-slide button shows all templates in a dense 4-column icon grid, letting power users insert without a full modal.

  • Small floating popover with upward-pointing arrow — not a full-screen modal
  • 4-column ultra-compact tile grid; tiles show a wireframe thumbnail and reveal name on hover
  • Group dividers as inline hairline separators with a tiny group label
  • Active tile gets accent ring + tick corner badge; hover shows accent-subtle background
  • Bottom bar shows the selected template name alongside Insert and Brand Kit buttons
