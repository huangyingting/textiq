Control Primitives Kit — Design Languages

Six distinct visual languages applied to the same atom set: toolbar buttons, icon buttons, segmented controls, tabs, selects, popovers, swatches, switches, tooltips, and dividers. All use the same var(--ds-*) tokens.

6 languages Static HTML mockups — open in browser Tokens: design-tokens.css
01

Flat Outline

Hairline 1px borders, flat fills, zero elevation. Every edge is drawn; depth is implied through placement, not shadow. Dense, precise, editorial.

02

Soft Raised

White raised surfaces with gentle drop shadows. Controls feel like physical keys with tactile hover feedback. Depth through light, not borders.

shadow-raised white surfaces elevated hover accent glow on

03

Pill Capsule

Every control is a fully-rounded pill (border-radius: 9999px). Friendly, airy, mobile-inspired. Swatches are circles, tabs sit in a pill strip.

04

Recessed Segment

Controls are set into sunken tracks with inset shadows. The active state "pops" a white raised thumb out of the recess — physical slot mechanism.

05

Glass Translucent

Frosted glass panes — translucent white fills with backdrop-filter: blur. Controls float above the page, revealing blurred color gradients beneath.

High Contrast Mono

Stark black and white. No color except the single accent token on active/selected only. 1.5px borders, bold type, invert hover. Precision instruments aesthetic.
