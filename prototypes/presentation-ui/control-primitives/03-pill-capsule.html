03 — Pill Capsule

Every control is a fully-rounded pill (border-radius: 9999px). Feels friendly, airy, and modern — inspired by mobile app toolbars and floating action clusters. Maximum personality with minimal visual weight.

  • All radii: 9999px (pill/capsule) — no sharp corners anywhere
  • Segmented control: pill track + filled accent pill for active segment
  • Tabs: pill strip with raised white active tab (shadow lifts it)
  • Tooltips: dark pill (inverse surface) for maximum contrast
  • Color swatches: circles, scale-up on hover with spring bounce
