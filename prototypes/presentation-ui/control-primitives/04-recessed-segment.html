04 — Recessed Segment

Controls are set into sunken tracks (var(--ds-surface-sunken) with inset shadow). The active state "pops" a thumb out of the recess — raised white card + drop shadow. Every interactive group looks like a physical slot.

  • Track: var(--ds-surface-sunken) + inset 0 1px 3px (inward shadow)
  • Active thumb: var(--ds-surface-raised) + var(--ds-shadow-raised) — pops out of track
  • Segmented control is the primary paradigm; all groups use the track idiom
  • Switch: deeply recessed off-state; raised accent for on
  • Inputs / triggers: sunken with inset shadow for "form field" feel
