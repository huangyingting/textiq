06 — High Contrast Mono

Stark black and white. No color except the single accent token for active/selected state. Strong borders (1.5px), bold type weight, uppercase labels. The language of precision instruments and developer tools — every state is unambiguous.

  • 1.5px solid borders using var(--ds-text-primary) — maximum contrast
  • No shadows, no gradients, no color except var(--ds-accent) for active state only
  • Hover = full background invert (black bg, white text)
  • Active = accent fill — the only color on the page
  • Tabs: uppercase small-caps, heavy accent underline
  • Segmented: hard-edge grid lines, accent fill for selection
