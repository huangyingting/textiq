Right Inspector Panel · Design Exploration

Six distinct visual directions for the TextIQ presentation editor's right-side properties panel. All mockups are static HTML using shared design-tokens.css — no frameworks, no CDNs, no build step.

6 variants var(--ds-*) tokens only Static mockups · design/inspector-panel/
01

Flat Sectioned Scroll

Clean flat layout with hairline dividers between sections. Comfortable row height with muted left-aligned labels.

  • Single-column stacked rows; 2-col grid for X/Y/W/H
  • Hairline border-top separates every section — no shadows
  • Active tab uses underline indicator in accent color

02

Collapsible Accordion

Each section is an expandable accordion — users collapse rarely-used groups to reduce scroll distance.

  • Chevron rotates on open/close with CSS transition
  • Template, Geometry, Style open by default; Effects & Layers closed
  • Tiny JS syncs aria-expanded with <details> open state
Open in new tab
03

Card Grouped

Sections as subtly raised cards floating on a sunken panel background — clear grouping without hard dividers.

  • Panel: ds-surface-sunken; cards: ds-surface + ds-shadow-raised
  • Rounded corners (ds-radius-lg) on every card
  • Inputs use sunken fill to visually recede into the card

04

Dense Two-Column

Maximally compact — X/Y/W/H in a 4-column row; template controls in 2-col grids; ~40% shorter than variant 01.

  • 4-col geometry row eliminates two rows vs stacked pairs
  • Template selects in 2-col grid: Tone/Density, Emphasis/Decoration
  • 22–24px row height; 9–10px sub-labels
Open in new tab
05

Segmented Header Tabs

Pill-track segmented control replaces the underline tab strip; a persistent section subnav lets users jump to any anchor.

  • Uses ds-segment-track / ds-segment-thumb tokens for the recessed pill
  • Section subnav (TMPL · GEO · FILL · TYPE · EFX · LYR) smooth-scrolls
  • Raised thumb shadow distinguishes active segment without color alone
Open in new tab
06

Inline Label Rows

Labels in a fixed 86px left column beside controls — eliminates stacked label-then-input for the highest density of all variants.

  • Fixed 86px label column ensures perfect vertical alignment throughout
  • Position (X+Y) and Size (W+H) each fit in one row as labeled pairs
  • 24–26px rows; no wasted vertical space between label and input
