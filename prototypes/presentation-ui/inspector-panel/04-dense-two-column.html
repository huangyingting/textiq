04 · Dense Two-Column

Maximally compact: all four geometry fields (X Y W H) appear in a single 4-column row; template controls in 2-col grid; fewer pixels per section.

  • X, Y, W, H in a 4-col grid (one row) — saves ~40px vs stacked pairs
  • Template selects in 2-col: Tone/Density, Emphasis/Decoration side-by-side
  • Row height 22–24px; labels 9–10px; section title at 10px
  • Still accessible: all labels associated to inputs via htmlFor / label
