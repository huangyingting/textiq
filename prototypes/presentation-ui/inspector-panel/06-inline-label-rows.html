06 · Inline Label Rows

Labels sit in a fixed 86px left column beside their controls — eliminating the stacked label-then-input pattern for maximum vertical compactness.

  • Fixed 86px label column ensures perfect alignment across all rows
  • X/Y and W/H each appear as labeled pairs in a single row — 50% fewer rows vs stacked
  • No section header margin wasted on vertical space; rows are 24–26px
  • Highest information density of all six variants while remaining legible
