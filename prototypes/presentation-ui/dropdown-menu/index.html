Dropdown / Select / Context Menu — Design Exploration

Six distinct visual directions for the shared dropdown, select, and context menu surface in the TextIQ presentation editor. Each design is self-contained and browser-openable, grounded in select-menu.tsx and stage-context-menu.tsx.

6 design directions var(--ds-*) tokens throughout Plain HTML + CSS · No frameworks Inline Lucide-style SVG icons Full anatomy demonstrated
