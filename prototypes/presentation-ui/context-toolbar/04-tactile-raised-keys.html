04 · Tactile Raised Keys

Each button is rendered as a miniature raised keycap — a 1 px bottom shadow line plus a soft depth shadow. Hovering lifts the key up (translateY(-1px)); pressing it pushes it down. The toolbar tray is sunken so keys appear to emerge from a physical surface.

  • Sunken tray container (surface-sunken) — keys emerge from it
  • Per-button raised shadow: border-bottom + depth shadow
  • Hover → translateY(-1px) + stronger shadow (lift)
  • Active press → translateY(+1px) + shadow collapse
  • Active toggle: accent-subtle background + accent border
Tactile key feedback Hover the buttons to feel the key lift. Each keycap has depth.
