02 · Compact Alert — Destructive Confirm

Ultra-compact alert shell (max 348 px) built for single-focus, high-consequence decisions. A strong backdrop and prominent danger icon stop the user before they commit.

  • Danger accent strip at panel top-edge signals severity before any text is read
  • Centered icon + title pattern puts the consequence in visual focus, not the metadata
  • Affected items listed with danger surface card — the full blast radius is always visible
  • Full-width stacked buttons ensure large touch targets; primary is bottom so it's thumb-reachable
  • Strong backdrop (--ds-backdrop-strong) + blur isolates the decision from the editor context
