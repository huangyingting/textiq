A chromatic gradient header band establishes strong visual hierarchy and emotional brand tone — ideal for high-value dialogs where context needs a bold anchor before the form.

  • Gradient hero band (accent → purple) carries the icon, title, and subtitle against a rich backdrop
  • Semi-transparent close button and icon badge use rgba tints so they don't clash with the gradient
  • Permission pills (View / Comment / Edit) replace radio buttons — tappable with active accent fill
  • Divider "or invite by email" section keeps the two collaboration flows visually separated
  • Footer-left info note balances the action buttons; monospace URL field signals "copyable" content
