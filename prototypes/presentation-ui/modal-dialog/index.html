Modal Dialog Shell · Design Exploration

Six distinct modal directions for the TextIQ presentation editor: centered classic, compact alert, hero illustrated, toolbar-footer checklist, side drawer, and bottom sheet. All mockups are self-contained HTML using shared design-tokens.css — no frameworks, no CDNs, no build step.

6 variants var(--ds-*) tokens only Static mockups · design/modal-dialog/ Round 2 · export preflight + destructive confirm + share + recovery
01

Centered Classic

The canonical centered-card shell over a dimmed, blurred editor. Export Preflight content: icon badge header, scrollable checklist body with pass/warn badges, footer with Cancel + Export.

  • Header: icon badge + title + subtitle + X close; body scrolls independently of footer
  • Checklist rows carry pass / warn status badges in semantic token colors
  • Footer: ghost Cancel + pill-shape primary Export; max-w 440 px

02

Compact Alert

Ultra-compact destructive confirm (max 348 px). Danger accent strip at top, centered Trash2 icon, "Delete 3 slides?" title, affected slides listed in a danger surface card, full-width stacked buttons.

  • Danger strip + strong backdrop signal severity before any text is read
  • Centered icon + title pattern keeps the consequence in visual focus
  • Full-width stacked buttons: Delete (danger) above Cancel — thumb-reachable on mobile

03

Hero Illustrated

Gradient hero header band (accent → purple) establishes strong visual hierarchy. Share dialog content: URL copy row, permission pill-picker, email invite field, footer with info note + Publish.

  • Gradient hero band with decorative circles; semi-transparent close button tinted for contrast
  • Permission pills (View / Comment / Edit) replace radio buttons — tap-friendly active fill
  • Monospace URL input signals "copyable"; one-click copy button anchored in-row

Toolbar Footer Checklist

Export Preflight with extended detail. Breadcrumb header, 4-cell summary stat strip (Passed / Warnings / Errors / Fallback tiers), grid-aligned checklist, split footer with icon toolbar + actions.

  • Summary stat cells give instant at-a-glance status before scanning the detail list
  • Grid-column checklist (icon · name+note · target · badge) aligns all columns perfectly

Side Drawer

Bottom Sheet

Anchored bottom sheet for conflict / unsaved-changes recovery. Drag handle, warning callout with revision detail, three recoverable-action cards (Keep / Discard / Dismiss), timestamp footer.
