06 / 06 Hover Action Overlay

Pristine resting state; per-slide actions materialise as a floating pill bar above the card on hover.

Zero-chrome at rest — just thumbnails and number badges. Hover reveals a polished floating action bar (drag handle · duplicate · delete) that pops up with a subtle entrance. Maximum focus on slide content.

  • Resting: only thumbnail + accent number badge — no visible buttons, no crowding
  • Hover: pill-shaped overlay bar floats above card with popover shadow, entrance translateY(–4 px) + opacity transition
  • Bar contains: ⠿ drag handle · divider · copy · trash — compact 26 px icon targets, pill border-radius
  • Filmstrip has extra top-padding so the floating bar has room; overflow-y:visible ensures nothing clips
