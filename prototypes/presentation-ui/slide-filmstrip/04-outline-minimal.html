04 / 06 Outline Minimal

Hairline 1 px cards, no fills — accent underline marker replaces the ring for the active slide.

Maximum whitespace, minimum chrome. Cards recede behind their content; a clean accent underbar and number colour shift are all that mark the current slide. Ideal for content-focused decks.

  • 1 px hairline border, transparent/white fill, no shadows by default — truly flush with the canvas area
  • Active: accent underline bar (full card width, 3 px) + accent-coloured slide number + subtle border tint
  • Flat rectangular action buttons (no glass, no blur) match the hairline aesthetic
  • Rail background matches page base (var(--ds-surface-base)) — filmstrip feels like a continuation of the editor
